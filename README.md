# Customer Behaviour Analysis 

##  Project Overview
This project focuses on analyzing customer shopping behaviour using Python and Jupyter Notebook.  
The goal is to understand customer demographics, purchasing patterns, and buying frequency to help businesses make data-driven decisions.

---

##  Tools & Technologies Used
- Python  
- Jupyter Notebook  
- Pandas  
- NumPy  
- Matplotlib / Seaborn  
- MySQL  
  

---

##  Dataset Description
The dataset contains customer purchase information with the following key columns:
- customer_id  
- age  
- gender  
- item_purchased  
- category  
- purchase_amount  
- location  
- subscription_status  
- payment_method  
- previous_purchases  
- frequency_of_purchases  
- purchase_frequency_days  

---

##  Key Analysis Performed
- Customer age group analysis  
- Gender-wise purchase behaviour  
- Category-wise sales analysis  
- Purchase frequency segmentation  
- Customer segmentation (New, Returning, Loyal customers)  
- Spending pattern analysis  

---

##  Insights & Findings
- Identified high-value customer segments  
- Found most popular product categories  
- Analyzed repeat customer behaviour  
- Observed purchase frequency trends  

---

##  Database Integration
- Connected Jupyter Notebook with **MySQL** 
- Stored cleaned and processed data into MySQL tables
- Executed SQL queries for further analysis
